# HTML and CSS Projects

This repository contains projects and assignments completed while studying HTML, CSS, JavaScript, and Bootstrap through The Tech Academy. These projects were created to develop foundational web development skills including page structure, styling, responsive layouts, navigation systems, forms, animations, and Bootstrap components.

## Academy Cinemas

This project is a movie theater website built using HTML, CSS, and Bootstrap 5. It contains a responsive navigation bar, promotional content, movie cards, forms, images, and other Bootstrap components used to create a modern theater website layout.

## Basic HTML Page

This project contains introductory HTML exercises focused on building basic webpage structure. It demonstrates the use of headings, paragraphs, metadata, and fundamental HTML document organization.

## Basic HTML and CSS

This project contains exercises covering HTML and CSS fundamentals. Topics include external stylesheets, tables, lists, text styling, HTML entities, and basic page formatting using CSS.

## Basic HTML and JavaScript

This project introduces basic JavaScript integration with HTML. It demonstrates linking JavaScript files, creating functions, manipulating webpage content, and working with simple user interactions.

## Creating CSS Effects

This project demonstrates CSS styling techniques including hover effects, navigation menus, image overlays, transitions, positioning, animations, and responsive layout concepts.

## HTML Documents

This collection contains introductory HTML assignments focused on page structure, images, videos, links, and multimedia content. It includes exercises that explore core HTML elements and document organization.

## Introduction to Bootstrap

This project introduces Bootstrap and its responsive grid system. It demonstrates the use of Bootstrap components, containers, rows, columns, images, and utility classes to create responsive webpage layouts.

## One-page Website

This project is a single-page website focused on 1990s hip-hop culture. It includes navigation links, content sections, images, and custom CSS styling within a one-page layout.

## Simple Recipes

This project is a recipe website built with HTML and CSS. It features navigation menus, recipe cards, image effects, flip-card interactions, content sections, and a contact form.

## The Pet Shop Website

This project is a pet shop website that showcases various pet categories using custom HTML and CSS. It includes navigation, image galleries, hover effects, animations, custom styling, and a favicon.
